# Publication data layer

Run publication scripts from `PROS_Pipeline/`; their small-data inputs below are addressed as `03_Public_Code/data/...`. This directory contains only the final-sample metadata and one explicitly archived RF handoff. No raw reads, VCFs, reference files, Stacks catalog, or sNMF project are copied into Git.

## Metadata

- `metadata/sample_metadata.csv`: 359 rows × 28 columns, ordered exactly as `../00_upstream/final_359_samples.tsv`. Source: `00_Metadata/sample_metadata_v2.csv`, restricted by exact SampleID; values unchanged. Includes all Bio1–Bio19 for RDA VIF selection. Removed `Species_ori`, `distance_to_coast_m`, `市.郡等`, and 17 non-final samples. Exact `Lat`/`Lon` are needed for IBD/map reproduction; **NEEDS REVIEW**: approve public release of precise sampling locations before publishing.
- `metadata/population_metadata.csv`: 46 rows × 11 columns. Source: `01_Data/population_distance_to_coast.csv`, restricted to the 46 final Pop_L3, retaining original non-classification fields and row order. `Species` now matches the final individual-level variety for **every** member of its Pop_L3 (including BOS10, BOS11, BOS14, BOS6, BOS8, IBR2, ISU11, ISU2); `Habitat_new` is likewise copied from final sample metadata. BOS4/FUJ4 are absent. Coordinates agree numerically with final samples; MUR3 differs only in floating-point text representation.
- `Table1_Variety` is a **separate 14-region manuscript display classification**, transcribed from the existing final `04_Results_Archive/13_Table1_260901/Table1_Island_Level_Final.csv` (blank repeated labels filled within each group). `06_tables_figures/03_table1_summary.R` uses this field solely to preserve that authoritative Table 1's original grouping/labels. It is **not** a Pop_L3/individual taxonomic assignment: BOS, IBR and ISU contain both varieties. Old `Species` values remain in `01_Data/population_distance_to_coast.csv` as historical provenance, not authoritative public classification; the final individual taxonomy follows the documented habitat-based update in `02_Scripts_Backend/00_Update_BOS_species_classification.R`. Do not infer individual classifications from Table 1's regional label.

## RF habitat handoff

`handoff/RF_Habitat_final_candidates.csv` is a byte-identical copy of `04_Results_Archive/08_RF_HabitatNew/Table_RF_Habitat_Final_Candidate_SNPs.csv` (relative to `PROS_Pipeline/`): **534 rows / 534 unique SNP_IDs**; source and copy SHA-256: `dc28df1caaafd850683704621dfe58c6248841ef83f31715e9db0c316835a0ac`. The later three-method intersection contains 21 SNPs; 534 is the *RF handoff*, not the consensus count.

This is an archived intermediate result from the original RF habitat workflow.
The historical Stage-1 percentage-screening producer is not currently available in executable form.
It is supplied to preserve reproducibility of the downstream three-method consensus analysis.
